# Quanto preciso tirar? 🎯

Calculadora de médias que mostra **quanto você precisa tirar nas avaliações
que faltam** para fechar a média desejada.

👉 **Use aqui:** https://phbr13.github.io/quanto-preciso-tirar

## 🎓 Só serve para o 2º período de Computação da UFSCar (2026)

Este app **não é genérico**. As matérias, pesos e datas são fixos e foram
copiados dos planos de ensino da minha turma:

- Arquitetura de Computadores
- Estatística Básica
- Lógica Matemática
- Geometria Analítica
- Programação Orientada a Objetos
- Algoritmos e Estrutura de Dados 1

Se você é de outro curso, outro semestre ou outra turma, **os cálculos
provavelmente estarão errados**. Mesmo para a minha turma, regras de
recuperação e frequência podem estar incompletas: **confira sempre o plano
de ensino oficial** no SIGA.

## ⚠️ Projeto vibecoded

Feito com ajuda de IA para resolver um problema real: organizar meu semestre.
**Não é uma vitrine das minhas habilidades de programação**, então o código
pode estar bagunçado. O que importa é o app funcionar.

## Como funciona

- Uma aba por matéria, cada uma com sua fórmula de média.
- Os dados ficam salvos **só no seu navegador** (localStorage). Não há
  servidor, conta nem coleta de dados.
- Use **Exportar/Importar backup** para levar suas notas a outro aparelho ou
  antes de limpar os dados do navegador.

## Contribuindo

PRs são bem-vindos! Ideias úteis:

- Corrigir fórmulas ou regras de recuperação das matérias acima
- Permitir criar/editar matérias pela interface (para outros cursos/semestres)
- Melhorias de acessibilidade e de design

Código gerado por IA é aceito, desde que você tenha testado. Abra uma issue
antes se for uma mudança grande.
