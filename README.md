# Quanto preciso tirar? 🎯

Calculadora de médias do semestre. Você preenche as notas que já tem
e ela mostra **quanto precisa tirar nas avaliações que faltam** para
fechar a média desejada.

👉 **Use aqui:** https://SEUUSUARIO.github.io/quanto-preciso-tirar

## ⚠️ Aviso: projeto vibecoded

Este projeto foi feito com ajuda de IA (vibe coding). Ele existe só
para resolver um problema real: organizar meu semestre. **Não é uma
vitrine das minhas habilidades de programação**, então o código pode
estar bagunçado. O que importa aqui é o app funcionar.

## Como funciona

- Uma aba por matéria, cada uma com sua fórmula de média.
- Os dados ficam salvos **só no seu navegador** (localStorage).
  Não há servidor, conta nem coleta de dados.
- Use **Exportar/Importar backup** para levar suas notas a outro
  aparelho ou se for limpar os dados do navegador.

## Limitações

- As matérias e fórmulas estão fixas no código (são as minhas).
  As regras de recuperação e frequência podem não estar completas.
  **Confira sempre o plano de ensino oficial.**

## Contribuindo

PRs são bem-vindos! Ideias úteis:

- Permitir criar/editar matérias e fórmulas pela interface
- Suporte a outras regras de recuperação
- Melhorias de acessibilidade e de design

Pode contribuir também com código gerado por IA, desde que você
tenha testado. Abra uma issue antes se for uma mudança grande.
